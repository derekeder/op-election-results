# Oak Park election results by precinct

An interactive map and table of precinct-level results for Oak Park races:

- April 7, 2015 consolidated election: Park District board, Elementary School District 97 board and High School District 200 board
- April 4, 2017 consolidated election: village trustee, village clerk, library board, Elementary School District 97 board, High School District 200 board, and the District 97 tax rate and bond referendums
- April 2, 2019 consolidated election: village trustee, Park District board, District 97 board and District 200 board
- April 6, 2021 consolidated election: village president, village clerk, village trustee, library board, District 97 board, District 200 board, Triton College trustee (2- and 6-year terms), Oak Park Township trustee, and the referendum on defunding the police department
- April 4, 2023 consolidated election: village trustee and High School District 200 board
- March 19, 2024 Democratic primary: 7th Congressional District, Cook County state's attorney, Clerk of the Circuit Court, Board of Review (3rd District) and County Board commissioner (1st District)
- April 1, 2025 consolidated election: village trustee, village president, library board, Elementary School District 97 board, High School District 200 board and Triton College trustee
- March 17, 2026 Democratic primary: U.S. Senate, comptroller, 7th Congressional District, 8th State House District, Cook County Board president, Cook County assessor and State Central Committeeperson (7th District)

The 2024 and 2026 primaries are left out of the page's menu for now (`HIDDEN_YEARS` in `js/app.js`), but their data is still built and included in `js/data.js`; remove a year from that list to show it again.

Every race except the village and library ones reaches beyond Oak Park; the page shows only Oak Park precincts. Only five Oak Park precincts (17, 25, 29, 30 and 31) are in the 8th State House District.

## Viewing it

`index.html` is a static page with no build step. Open it directly in a browser, or publish it with GitHub Pages. Text is set in Open Sans and Merriweather from Google Fonts; without an internet connection it falls back to Helvetica/Arial and Georgia.

The URL records the selected race and map view, so a specific view can be shared, e.g. `index.html?race=d97_2025&view=Becky+Perez`. Race ids are the data file names listed below.

- `css/style.css`: page styles
- `js/d3.v7.9.0.min.js`: the D3 charting library (bundled locally)
- `js/data.js`: the results and precinct boundaries the page draws from (generated by `scripts/extract_results.py`)
- `js/dash.js`: small runtime that serves the data and tracks the selected race and map view
- `js/app.js`: builds the race tabs, totals, map and table

## Basemap

The precinct map is drawn with Leaflet (`js/leaflet.1.9.4.js`, bundled locally) over CARTO's Positron basemap, or Dark Matter in dark mode. The street labels are a separate tile layer drawn above the precincts. CARTO requires an API key, set as `CARTO_KEY` in `js/app.js`. The key is visible to anyone viewing the page, so restrict it to the site's domain in your CARTO account. The basemap tiles need an internet connection; without one the precincts still draw on a plain background.

## Password

The page asks for a password before showing anything, and each browser remembers it once entered. This only keeps casual visitors out: the data files (`js/data.js` and the `data/` folder) can still be downloaded directly by anyone who knows their URLs.

`js/gate.js` stores a SHA-256 hash of the password, not the password itself. Entries are trimmed and lowercased before checking. To change the password, replace `HASH` with the output of:

```
node -e "console.log(require('crypto').createHash('sha256').update('new password').digest('hex'))"
```

## Publishing on GitHub Pages

1. Create a new public repository on GitHub.
2. Upload everything in this folder (keep `index.html` at the top level).
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to "Deploy from a branch", pick the `main` branch and the `/ (root)` folder, and save.
5. After a minute or two the site will be live at `https://<your-username>.github.io/<repository-name>/`.

## Data

The `data/source` folder holds the Cook County Clerk precinct results spreadsheets. To regenerate the JSON files and `js/data.js` after changing them, run:

```
python3 scripts/extract_results.py
```

To add a race, drop its spreadsheet in `data/source`, add it to `RACES` in the script, run it, and add a matching entry to `RACES` at the top of `js/app.js`.

The 2015, 2017, 2019 and 2021 results come from the clerk's suburban-wide precinct canvass workbooks (`Precinct Canvass 2015.xls`, `Precinct Canvass 2017.xls`, `Precinct Canvass Apr 2019.xls` and `Apr 2021 Precinct Canvass.xls`), which hold every contest in suburban Cook. `scripts/extract_canvass.py` pulls the Oak Park contests listed in its `CANVASS` setting into one CSV per race in `data/source` (e.g. `2019-OP-trustee-canvass.csv`), checking them against the workbook's contest totals. It needs the `xlrd` package (`pip install xlrd`) and only has to be rerun when a canvass workbook changes; `extract_results.py` reads the CSVs. Uncontested contests (2015 village trustee, library board and Triton; 2017 village president, township offices, park board and Triton; 2019 library board and Triton; 2021 park board and township supervisor, clerk and assessor) aren't included.

- `senate_2026.json`, `comptroller_2026.json`, `congress7_2026.json`, `staterep8_2026.json`, `countypres_2026.json`, `assessor_2026.json`, `statecentral_2026.json`, `congress7_2024.json`, `statesattorney_2024.json`, `circuitclerk_2024.json`, `boardofreview_2024.json`, `countyboard1_2024.json`, `trustee_2025.json`, `president_2025.json`, `library_2025.json`, `d97_2025.json`, `d200_2025.json`, `triton_2025.json`, `trustee_2023.json`, `d200_2023.json`: one row per precinct with registered voters, ballots cast, turnout, each candidate's votes, total votes and the top vote-getter (2023 files use 2023 precinct numbers).

- `demographics.json`: estimated residents by race and ethnicity and by age group (counts and percentages), households, median household income, homeowners and renters, single- and multi-unit housing, household types (counts and percentages), and people in households and persons per household for each current precinct, from `scripts/demographics.py`.
- `parkdistrict_2015.json`, `d97_2015.json`, `d200_2015.json`: the same, for the 38 precincts Oak Park had in 2015.
- `clerk_2017.json`, `trustee_2017.json`, `library_2017.json`, `d97_2017.json`, `d200_2017.json`, `d97rate_2017.json`, `d97bonds_2017.json`, `trustee_2019.json`, `parkdistrict_2019.json`, `d97_2019.json`, `d200_2019.json`: the same, for the 37 precincts Oak Park had before 2022.

## Sources and notes

- Results: Cook County Clerk precinct results spreadsheets for each race.
  - 2009 - present: https://www.cookcountyclerkil.gov/elections/results-and-election-data/election-data/precinct-canvasses
  - 2022 to present: https://www.cookcountyclerkil.gov/elections/results-and-election-data/election-results
- Boundaries: Cook County suburban election precincts map.
- Oak Park had 38 precincts through 2015. For 2017, precincts 17 and 36 were merged into a new 17 and precinct 38 was renumbered 36; the other lines stayed the same.
- Oak Park had 37 precincts from 2017 through 2021; they were redrawn into today's 32 in 2022. The 2015, 2017, 2019 and 2021 results are mapped on the old lines and their precinct numbers don't correspond to today's, so they aren't part of the progressive lean. Registered voters per precinct track closely from 2017 to 2021, consistent with the lines being unchanged between those elections.
- The 2023 election used the same precinct lines as today, under different numbers; precincts were renumbered 1–32 in 2024. 2023 precinct 33 is today's 30, 34 is today's 21, and 35 is today's 7; the rest kept their numbers.
- Write-in votes are left out of the 2017 and 2019 races, matching the other races' spreadsheets, which don't list them.
- Trustee races were vote-for-3, so a candidate's percentage is their share of all trustee votes cast, not of voters.

## Progressive lean

The **Progressive lean** view scores each precinct on how progressive or conservative it votes compared with the rest of Oak Park. The candidates counted on each side are listed in `data/candidate_labels.csv`, one row for every candidate in every consolidated (odd-year) election, with its race id, name (exactly as in the results spreadsheet) and label: `progressive`, `moderate`, `conservative` or blank. Candidates with a blank label are ignored, and only races with at least one progressive and one conservative count. Only the 2023 and 2025 local elections are used (`LEAN_YEARS` in the script); the 2015–2021 races are listed, unlabeled, but ignored, since their precincts don't match today's. The even-year primaries aren't part of the lean and aren't listed. Edit the file (in a spreadsheet or text editor) and rerun the script to change the index.

For each race, a precinct's lean is the progressive candidates' share of the vote minus the conservative candidates' share. That is measured against the average Oak Park precinct and divided by the spread across precincts, so every race counts equally regardless of how close it was. The index is the average over the races: above 0 leans more progressive than the average precinct, below 0 more conservative. Because Oak Park as a whole votes progressive, the index is relative: a "conservative" precinct is conservative for Oak Park.

For an absolute picture, which is what the map shows, candidates can also be labeled moderate. Each race is scored from −100 (all conservative) to +100 (all progressive), with 0 a tie: the average progressive candidate's votes minus the average conservative candidate's, divided by the progressive, moderate and conservative averages combined. Moderates count as neutral, so precincts that voted for them are pulled toward the center. Using each side's average keeps a race with two progressives and one conservative from being lopsided. `lean.json` records each precinct's absolute lean averaged over the races (`abs_lean_pts`) and how many races the progressive side outpolled the conservative (`h2h_won` of `h2h_races`). Each race also has its absolute lean (`<race>_abs`). Only races with candidates named on both sides count toward these; unlabeled candidates are ignored.

Only the local races from the 2023 and 2025 consolidated elections are used: 2023 and 2025 village trustee, 2023 and 2025 District 200, 2025 village president, library board and District 97.

## Demographics

The **Demographics** view shows each precinct's race and ethnicity, age, median household income, share of homeowners and renters, share of single- and multi-unit housing, household type, and persons per household, estimated from the 2020–2024 American Community Survey 5-year estimates. Race and ethnicity comes from Table B03002 (Hispanic or Latino origin by race): white, Black and Asian (each not Hispanic), Hispanic or Latino (any race), and other or multiracial (not Hispanic: American Indian, Pacific Islander, some other race, or two or more races). Age comes from Table B01001 (sex by age), grouped as under 18, 18–29, 30–44, 45–64 and 65 and older. Income comes from Table B19001 (household income in 16 brackets), homeowners and renters from Table B25003 (tenure of occupied housing units), single- and multi-unit housing from Table B25024 (units in structure, counting all housing units, occupied or vacant; single-unit means detached or attached single-family homes), and household type from Table B11001: married couples, families with a male or female householder and no spouse present, people living alone, and other nonfamily households such as roommates. Persons per household is people living in households (Table B11002, everyone except group quarters such as nursing homes) divided by households; the village figure matches the ACS average household size (Table B25010).

The ACS reports by census block group, and block groups don't match precinct lines. `scripts/demographics.py` splits each block group's counts among its 2020 census blocks in proportion to their 2020 population, assigns each block to the precinct containing its center point, and adds them up. Household and housing unit counts (income, tenure, building type and household type) are split by 2020 housing units instead of population. Medians can't be added up, so each precinct's median household income is interpolated within the income bracket holding its middle household; the top bracket is $200,000 or more, so higher medians are shown as $200,000+. The village median estimated this way is within 1% of the ACS figure for Oak Park. The precinct estimates add up to the ACS total for Oak Park village within 0.1% for every group. They are still survey estimates with margins of error, especially for smaller groups and precincts.

To refresh the data, get a free Census API key at https://api.census.gov/data/key_signup.html, then run:

```
CENSUS_API_KEY=your-key python3 scripts/demographics.py
python3 scripts/extract_results.py
```

The key is read from the environment and isn't stored in the repository.
